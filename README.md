## Estructura del repositorio

```text

├── homework/            Tareas resueltas, una carpeta por tarea
```

## Cómo usar este repositorio

```bash
git clone https://github.com/NatoRemolina/GCI-World-Data-Science-2026.git
cd GCI-World-Data-Science-2026
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Más detalle en [docs/setup.md](docs/setup.md).

## Sobre el material del curso

Las diapositivas, notebooks de clase, soluciones oficiales y datasets son propiedad del Matsuo-Iwasawa Lab (Universidad de Tokio) y su distribución a terceros no está permitida. Por eso la carpeta `course-materials/` está excluida del control de versiones y este repositorio contiene únicamente mi trabajo personal.
