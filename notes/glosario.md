# Glosario inglés → español

Términos del curso en su idioma original con su equivalente y una definición breve. Ordenado por sesión.

## Session 1 · Introducción a la ciencia de datos

| Inglés | Español | Definición |
|---|---|---|
| Data science | Ciencia de datos | Disciplina que extrae conocimiento y apoya decisiones a partir de datos. |
| Dataset | Conjunto de datos | Colección estructurada de observaciones (filas) y variables (columnas). |
| Feature | Característica / variable | Atributo medible de cada observación. |
| Insight | Hallazgo | Conclusión útil y accionable obtenida del análisis. |
| Hypothesis | Hipótesis | Suposición que se contrasta con los datos. |

## Session 2 · NumPy

| Inglés | Español | Definición |
|---|---|---|
| Array | Arreglo | Estructura de NumPy con elementos de un solo tipo en memoria contigua. |
| Vectorization | Vectorización | Aplicar una operación a todo un arreglo sin ciclos explícitos. |
| Broadcasting | Difusión | Regla que permite operar arreglos de formas distintas pero compatibles. |
| Boolean mask | Máscara booleana | Arreglo de `True`/`False` que selecciona elementos. |
| Shape | Forma | Tamaño de cada dimensión de un arreglo, p. ej. `(3, 4)`. |
| Axis | Eje | Dimensión sobre la que se aplica una operación (`axis=0` filas, `axis=1` columnas). |
| Slicing | Rebanado | Extraer una porción de un arreglo con `inicio:fin:paso`. |

## Session 3 · pandas

| Inglés | Español | Definición |
|---|---|---|
| DataFrame | DataFrame / tabla | Estructura tabular con columnas etiquetadas de tipos posiblemente distintos. |
| Series | Serie | Columna unidimensional con índice. |
| Missing value (NaN) | Valor faltante | Dato ausente; en pandas se representa como `NaN` o `NA`. |
| Data cleaning | Limpieza de datos | Corregir, eliminar o imputar datos erróneos o faltantes. |
| Group by | Agrupar por | Dividir los datos en grupos para aplicar agregaciones. |
| Aggregation | Agregación | Resumir varios valores en uno (media, suma, conteo). |
| Merge / join | Combinación / unión | Unir tablas a partir de columnas clave. |
| Pivot table | Tabla dinámica | Reorganizar datos resumiendo valores por filas y columnas. |

## Session 4 · Visualización

| Inglés | Español | Definición |
|---|---|---|
| Figure / Axes | Figura / ejes | Lienzo completo y cada área de gráfico dentro de él en Matplotlib. |
| Histogram | Histograma | Distribución de frecuencias de una variable numérica. |
| Scatter plot | Diagrama de dispersión | Relación entre dos variables numéricas. |
| Box plot | Diagrama de caja | Mediana, cuartiles y valores atípicos de una distribución. |
| Pareto chart | Diagrama de Pareto | Barras ordenadas de forma descendente más una línea acumulada. |
| Decile | Decil | Cada una de las 10 partes iguales en que se divide un conjunto ordenado. |
| Cumulative proportion | Proporción acumulada | Suma progresiva de las proporciones hasta cada grupo. |

## Session 5 · Aprendizaje supervisado

| Inglés | Español | Definición |
|---|---|---|
| Supervised learning | Aprendizaje supervisado | Aprender una función a partir de ejemplos con su respuesta conocida. |
| Target / label | Variable objetivo / etiqueta | Lo que el modelo debe predecir. |
| Explanatory variable | Variable explicativa | Entrada usada para predecir el objetivo. |
| Linear regression | Regresión lineal | Modelo que ajusta una relación lineal entre variables. |
| Coefficient of determination (R²) | Coeficiente de determinación | Proporción de la varianza del objetivo explicada por el modelo. |
| Training / test set | Conjunto de entrenamiento / prueba | Datos para ajustar el modelo y para evaluarlo sin sesgo. |
| Overfitting | Sobreajuste | El modelo memoriza el entrenamiento y generaliza mal. |
| Cross-validation | Validación cruzada | Evaluar el modelo rotando particiones de los datos. |
| Hyperparameter tuning | Ajuste de hiperparámetros | Buscar la configuración del modelo que mejor generaliza. |
